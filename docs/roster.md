## Сообщения

1. Шапка (всегда одно сообщение):

```
# Состав Akiyama
## Численность: {N}
```

`N` — уникальные люди с хотя бы одной семейной ролью, не боты.

2. Дальше **каждое непустое** сечение ранга — отдельное сообщение:

```
## {Название роли}
<@id>
<@id>
```

Строка — **только тег участника** (`<@id>`). Discord сам подставит актуальный
ник, поэтому имя из ника бот не разбирает. Форма ники в этом боте
не используется.

- Пустых секций нет.
- Порядок секций — как в `RANK_ROLES` сверху вниз.
- Человек с несколькими семейными ролями попадает **во все** свои секции.
- Внутри секции: A→Z по нику как он есть (`nick` или отображаемое имя), без учёта регистра. Ничья — по user id.
- Лимит 2000 символов: то же `## Роль` + продолжение списка в следующем сообщении.

## Как писать, чтобы не пинговать

1. Собрать тексты всех сообщений заранее.
2. Снести канал полностью.
3. Отправить столько сообщений, сколько нужно, содержимое — `.`
4. Отредактировать каждое в боевой текст.
5. Проверить целостность.
6. Пункты 2–5 — до 3 попыток.

## Целостность после отправки

Ок, только если в канале ровно наши сообщения, число совпало, текст каждого совпал.

Иначе: удалить всё и retry. После 3 провалов:

- в канале состава: `Возникла проблема при отправке состава`;
- в owner-чат — тег руководства + ошибка;
- **стоп** до `/refresh`. Ни нули, ни роли сами не переотправляют.

## Когда что делать

| Событие | Действие |
|---------|----------|
| 00:00 МСК | Полная переотправка (точки → edit), если не fail-state |
| Роль / ник / вход / выход | Пересобрать тексты. Число сообщений то же → только edit. Иначе точки |
| Сообщение состава удалили / сменили | Полная переотправка |
| Чужой пост в канале | Удалить чужое. Если не вышло — полная переотправка |
| Рестарт бота | Сверить канал. Целое → edit. Дырки / лишнее → точки |
| `/refresh` | Снять fail-state, полная переотправка (до 3 попыток) |

Параллельные события — очередь, один проход за раз.
